## POST 发表评论

POST /comments

对指定笔记（targetType=1）或攻略（targetType=2）发表评论或回复他人评论。
【必填】targetType — 目标类型：1=笔记，2=攻略；非 1/2 返回 2001
【必填】targetId   — 目标笔记/攻略 ID，目标不存在返回 404
【必填】content    — 评论内容，最长 300 字
【可选】replyToId  — 被回复的一级评论 ID；空 = 一级评论，非空 = 二级评论（回复）

错误码：401 未登录/令牌无效（请提供认证令牌）；400 参数校验失败（content 为空/超长、参数类型错误）；2001 参数错误（targetType 非 1/2）；404 目标笔记/攻略不存在；500 服务器内部错误。

> Body 请求参数

```json
{
    "targetType": 1,
    "targetId": 9,
    "content": "镇上租车很方便",
    "replyToId": "1"
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 否 |none|
|» targetType|body|integer| 是 |none|
|» targetId|body|integer| 是 |none|
|» content|body|string| 是 |none|
|» replyToId|body|string| 否 |none|

> 返回示例

> 200 Response

```json
{
    "code": 0,
    "message": "成功",
    "data": {
        "id": "3",
        "user": {
            "id": "1",

        },
```

## GET 获取评论列表

GET /comments

分页获取指定笔记（targetType=1）或攻略（targetType=2）的一级评论列表，每个一级评论下默认返回前 2 条二级评论（展开更多请调用「获取二级评论列表」接口）。
【必填】targetType — 目标类型：1=笔记，2=攻略；非 1/2 返回 2001
【必填】targetId   — 目标笔记/攻略 ID
【必填】page       — 页码，从 1 开始
【必填】size       — 每页条数，最大 100

排序规则：一级评论按综合热度（热度 = 点赞数 + 回复数）降序，热度相同按时间倒序；二级评论按时间正序。

错误码：401 未登录/令牌无效；400 参数校验失败；2001 参数错误（targetType 非 1/2）；500 服务器内部错误。

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|targetType|query|integer| 是 |目标类型：1=笔记，2=攻略|
|targetId|query|integer| 是 |目标笔记/攻略 ID|
|page|query|integer| 是 |页码，从 1 开始|
|size|query|integer| 是 |每页条数，最大 100|

## POST 点赞 / 取消点赞评论

POST /comments/{id}/like

切换式接口：已点赞则取消，未点赞则点赞，返回操作后的最新状态。
错误码：401 未登录/令牌无效（请提供认证令牌）；400 id 格式不正确（参数错误: id格式不正确）；404 评论不存在；500 服务器内部错误。

## DELETE 删除评论

DELETE /comments/{id}

仅评论者本人可删除，采用软删除（delete_time 置位，列表查询天然过滤）。status 字段保留给笔记生命周期管理（后台笔记下架/恢复的批量状态同步会自动跳过已软删评论）。
错误码：401 未登录/令牌无效（请提供认证令牌）；400 id 格式不正确（参数错误: id格式不正确）；403 无权删除他人评论；404 评论不存在；500 服务器内部错误。

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|id|path|string| 是 |评论 ID|

> 返回示例

> 200 Response

```json
{
    "code": 0,
    "message": "成功",
    "data": {}
}
```

## GET 获取二级评论列表（加载更多）

GET /comments/{id}/replies

分页获取指定一级评论（:id）下的二级回复，用于一级评论「展开」时加载更多（前端建议 size=5）。
【必填】page — 页码，从 1 开始
【必填】size — 每页条数，最大 100

二级评论按时间正序，列表项为评论对象（无嵌套 replies）。

错误码：401 未登录/令牌无效；400 id 格式不正确（参数错误: id格式不正确）；404 一级评论不存在；500 服务器内部错误。

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|id|path|string| 是 |一级评论 ID|
|page|query|integer| 是 |页码，从 1 开始|
|size|query|integer| 是 |每页条数，最大 100|
