## 开发任务：途友·个人主页（静态页面）

### 一、页面概述

完成「途友」App 的个人主页（`src/pages/Profile/index.tsx`），展示用户个人信息、社交数据、内容分类入口。**本次为纯静态页面**，无需对接接口，使用 Mock 数据填充展示。


### 二、页面结构（自上而下）

```

───────────────────────────
│                             │
│┌──────────┐  山林旅人        │← 用户昵称（大号，加粗）    (左侧头像，靠近头像右侧是上面昵称，下面个性签名，
││  👤 头像 │                 │  ← 用户头像（圆形，大尺寸）右侧是一支笔写横线的图标，点击图标是编辑页)
│└──────────┘ 热爱徒步，每周一山│← 个人签名（小号，灰色）
│                         │
│   23    156    328       │  ← 社交数据（横向排列）都是白色字体，数据粗，文字细，数据字体颜色要比文字字体颜色亮
│   笔记   关注   粉丝     │（以上均是在背景图片上显示，背景图片有自下而上的由黑色到灰色到浅的渐变效果）背景图片下边两个角有圆角
│                         │（点击笔记是笔记列表，点击关注是关注列表，点击粉丝是粉丝列表）
│  ┌───────────────────┐  │
│  │ 我的内容           │  │  ← 功能入口（网格布局）
│  │ 我的收藏           │  │我的内容里是用户发布的笔记和攻略列表
│  │ 我的点赞           │  │我的内容里是用户点赞的笔记和攻略列表
│  │ 我的活动           │  │
│  │ 设置              │  │
│  └───────────────────┘  │
├─────────────────────────┤
│  社区  活动  消息  我的   │  ← 底部TabBar（"我的"高亮）
└─────────────────────────┘
```


### 三、各区域详细拆解

#### 3.1 顶部导航栏（HeaderNavBar）

| 元素 | 内容                 | 说明             |
| ---- | -------------------- | ---------------- |
| 左侧 | 返回箭头（←）        | 点击返回上一页   |
| 中间 | 用户昵称（山林旅人） | 显示当前用户昵称 |
| 右侧 | 无                   | 留空             |

#### 3.2 用户信息区

**布局**：居中排列

| 元素 | 内容               | 样式说明                                         |
| ---- | ------------------ | ------------------------------------------------ |
| 头像 | 用户头像图片       | 大尺寸圆形（如 120px），使用 Avatar 组件或自定义 |
| 昵称 | 山林旅人           | 字号较大（如 36px），加粗                        |
| 签名 | 热爱徒步，每周一山 | 字号较小（如 24px），灰色（#999）                |

**Mock 数据**：
```javascript
const userInfo = {
  avatar: 'https://picsum.photos/200?random=1',
  nickname: '山林旅人',
  signature: '热爱徒步，每周一山'
}
```

#### 3.3 社交数据区

**布局**：横向三等分排列

| 数据 | 数值 | 标签 | 说明                 |
| ---- | ---- | ---- | -------------------- |
| 笔记 | 23   | 笔记 | 用户发布的笔记数量   |
| 关注 | 156  | 关注 | 用户关注的其他人数量 |
| 粉丝 | 328  | 粉丝 | 关注用户的人数       |

**样式**：
- 三个数据块横向均匀分布
- 数值：大号、加粗、深色（如 32px）
- 标签：小号、灰色（如 24px）

**Mock 数据**：
```javascript
const socialStats = {
  notes: 23,
  following: 156,
  followers: 328
}
```

#### 3.4 功能入口区（4宫格）

**布局**：2×2 网格，每个入口包含图标 + 文字

| 入口     | 图标            | 文字     | 点击行为（占位）         |
| -------- | --------------- | -------- | ------------------------ |
| 我的笔记 | 📓 或 自定义图标 | 我的笔记 | Toast 提示"跳转笔记列表" |
| 我的收藏 | ⭐ 或 自定义图标 | 我的收藏 | Toast 提示"跳转收藏列表" |
| 我的活动 | 🏕️ 或 自定义图标 | 我的活动 | Toast 提示"跳转我的活动" |
| 设置     | ⚙️ 或 自定义图标 | 设置     | Toast 提示"跳转设置页"   |

**样式**：
- 每个入口居中对齐
- 图标尺寸适中（如 48px）
- 图标下方显示文字（如 26px）
- 卡片背景白色，带圆角和阴影


### 四、组件使用说明

| 区域     | 组件             | 来源               | 说明                           |
| -------- | ---------------- | ------------------ | ------------------------------ |
| 顶部导航 | `HeaderNavBar`   | 已封装             | 左箭头返回，中间显示"山林旅人" |
| 用户头像 | `Avatar`         | 已封装             | 大尺寸圆形头像                 |
| 功能入口 | `View` + `Image` | 自定义             | 2×2 网格布局                   |
| 底部导航 | `TabBar`         | 已封装（或自定义） | "我的"高亮                     |

**注意**：如果项目中没有 TabBar 组件，可自行实现一个简单的底部导航。

### 六、交互与状态

#### 6.1 顶部返回
- 点击返回箭头 → `Taro.navigateBack()` 返回上一页

#### 6.2 功能入口点击（占位交互）
- 点击任意功能入口 → `Taro.showToast({ title: '功能开发中', icon: 'none' })`

#### 6.3 社交数据点击（占位交互）
- 点击"关注"/"粉丝"数据 → Toast 提示"跳转关注列表/粉丝列表"

### 九、开发顺序建议

```

```


### 十、注意事项

1. **本次为纯静态页面**：不需要对接接口，所有数据使用 Mock
2. **头像使用 picsum.photos** 或项目内占位图
3. **底部 TabBar**：如果项目已有 TabBar 组件直接复用，没有则新建简易版
4. **功能入口图标**：可使用 Emoji 或项目内 SVG/字体图标
5. **点击交互**：所有点击均为占位 Toast 提示，不跳转实际页面
6. **头像颜色**：可参考设计稿使用渐变背景（如橙色渐变）
