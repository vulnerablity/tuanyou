


# 前台/前后台文件上传接口实现

## POST 图片批量上传

POST /upload/images

批量上传图片（1~5 张，每张 ≤ 5MB）。图片内容用此接口，第一张为封面。头像/活动封面/个人主页背景图传 1 张即可。后端按 magic bytes 校验格式（仅支持 jpg/jpeg/png/gif/webp），jpeg/png 自动去 EXIF + 最长边 1920 压缩 + 质量 85，gif/webp 原样。

> Body 请求参数

```yaml
files: string

```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|Authorization|header|string| 是 |none|
|body|body|object| 否 |none|
|» files|body|string(binary)| 是 |图片文件，1~5 个，单张 ≤ 5MB|

> 返回示例

> 200 Response

```json
{
  "code": 0,
  "message": "成功",
  "data": {
    "urls": [
      "https://tuyou1.oss-cn-beijing.aliyuncs.com/images/2026/08/08/20260808_153045_a1b2c3.png",
      "https://tuyou1.oss-cn-beijing.aliyuncs.com/images/2026/08/08/20260808_153046_c4d5e6.jpg"
    ]
  }
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|

### 返回数据结构

状态码 **200**

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|true|none||none|
|» message|string|true|none||none|
|» data|object|true|none||none|
|»» urls|[string]|true|none||none|

## POST 单个视频上传

POST /upload/video

上传单个视频。允许类型 mp4/mov/avi/mkv/webm，单个 ≤ 300MB，后端流式上传不占内存。
【只能传一个】视频内容只有一个视频，无批量视频接口。
【封面】不单独存封面文件：coverUrl = videoUrl + ?x-oss-process=video/snapshot,t_0,f_jpg，访问时由 OSS 即时截帧生成。
【发布】前端把 coverUrl 填入 images[0]，videoUrl 填入 videoUrl 字段。

> Body 请求参数

```yaml
file: string

```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|Authorization|header|string| 是 |none|
|body|body|object| 否 |none|
|» file|body|string(binary)| 是 |视频文件，单个 ≤ 300MB（视频内容只能传一个）|

> 返回示例

> 200 Response

```json
{
  "code": 0,
  "message": "成功",
  "data": {
    "videoUrl": "https://tuyou1.oss-cn-beijing.aliyuncs.com/video/2026/08/08/20260808_153045_a1b2c3.mp4",
    "coverUrl": "https://tuyou1.oss-cn-beijing.aliyuncs.com/video/2026/08/08/20260808_153045_a1b2c3.mp4?x-oss-process=video/snapshot,t_0,f_jpg"
  }
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|

### 返回数据结构

状态码 **200**

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|true|none||none|
|» message|string|true|none||none|
|» data|object|true|none||none|
|»» videoUrl|string|true|none||none|
|»» coverUrl|string|true|none||none|
