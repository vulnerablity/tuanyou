# 前台/消息通知

## GET 获取互动消息列表

GET /messages/interactions

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|page|query|integer| 否 |none|
|size|query|integer| 否 |none|

> 返回示例

> 200 Response

```json
{
    "code": 0,
    "message": "成功",
    "data": {
        "list": [
            {
                "id": "6",
                "msgType": 1,
                "content": "你的《雨崩村徒步：梅里雪山脚下的世外桃源》收到了一条新评论：雨崩真的像世外桃源，梅里雪山太神圣了",
                "sendTime": "2026-08-06 09:00:00",
                "isRead": 1,
                "sender": {
                    "id": "3",
                    "nickname": "骑行老王",
                    "avatar": "https://picsum.photos/id/1084/200/200"
                }
            }
        ],
        "total": 1,
        "page": 1,
        "size": 10,
        "total_page": 1
    }
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|

|» code|integer|true|none||none|

|» data|object|true|none||none|
|»» list|[object]|true|none||none|
|»»» id|string|false|none||none|
|»»» msgId|string|false|none||none|
|»»» templateId|integer|false|none||none|
|»»» senderId|string|false|none||none|

|»»» content|string|false|none||none|
