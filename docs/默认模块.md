
# 前台标签模块接口

## GET 获取标签列表

GET /common/tags

返回所有启用（status=1）的标签，按 id 升序。
供笔记/攻略发布时选择标签：返回的 tagName 原样传给 POST /notes 或 POST /guides 的 tags 字段

> 返回示例

> 200 Response

```json
{
  "code": 0,
  "message": "成功",
  "data": [
    { "id": 1, "tagName": "千岛湖" },
    { "id": 2, "tagName": "环湖" },
    { "id": 3, "tagName": "徒步" }
  ]
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|

### 返回数据结构

状态码 **200**

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|true|none||none|
|» message|string|true|none||none|
|» data|[object]|true|none||none|
|»» id|string|true|none||none|
|»» tagName|string|true|none||none|
