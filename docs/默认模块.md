## POST 创建活动

POST /activities

仅领队（role=0）可创建。

【必填】title            — 活动标题，最大50字
【必填】category         — 活动分类：徒步/露营/骑行/登山/跑步/攀岩/溯溪
【必填】coverImg         — 封面图URL（仅1张）
【必填】address          — 活动举办地点
【必填】startTime        — 开始时间 "YYYY-MM-DD HH:mm"，必须晚于当前时间 + 48小时
【必填】endTime          — 结束时间
【必填】price            — 费用，0=免费，必须为正数
【必填】maxPeople        — 人数上限
【必填】difficulty        — 难度：入门/中等/中高等/高等
【必填】activityContent  — 活动介绍，最长2000字

signUpStart/signUpEnd 由后端自动计算（signUpStart=创建时间，signUpEnd=开始时间-48h），前端无需传入。

> Body 请求参数

```json
{
  "title": "楠溪江溯溪一日",
  "category": "溯溪",
  "coverImg": "https://example.com/cover.jpg",
  "address": "浙江温州·楠溪江",
  "startTime": "2026-08-15 09:00",
  "endTime": "2026-08-15 17:00",
  "price": 0,
  "maxPeople": 15,
  "difficulty": "中等",
  "activityContent": "溯溪一日体验线..."
}
```

## GET 获取活动列表

GET /activities

获取活动列表，按分类筛选，分页返回。

【可选】category — 活动分类：徒步/露营/骑行/登山/跑步/攀岩/溯溪，不传=全部，传非法值返回2001
【必填】page     — 页码，从1开始
【必填】size     — 每页条数，最大100

无幻灯片/Banner；activityStatus 由后端按时间自动计算（报名中/进行中/已结束），signUpEnd = 开始时间-48h；joined 为当前用户是否已报名

|page|query|string| 是 |none|
|size|query|string| 是 |none|

## POST 报名/取消报名

POST /activities/{id}/signup

切换式接口：已报名则取消，未报名则报名。

报名校验：
- 活动不存在/已删除 → 404
- 活动已满员 → 2001
- 不在报名时间内（signUpStart ~ signUpEnd） → 2001
- 活动已结束 → 2001

返回 {isJoined: bool, currentPeople: int}

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|id|path|string| 是 |none|

> 返回示例

> 200 Response

```json
{
  "code": 0,
  "message": "成功",
  "data": {
    "isJoined": true,
    "currentPeople": 9
  }
}
```
